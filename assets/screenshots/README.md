# Capturas de tela reais — PENDENTES

Este diretório não contém prints fabricados. Capture **do aplicativo Flutter realmente executado** cada tela listada no README principal. Sugestão de comando após navegar no emulador até cada tela:

```bash
flutter screenshot -o assets/screenshots/02-inicio.png
```

Repita para os 10 nomes. Antes de capturar a tela de consentimento, revogue o consentimento no app; para preservar o cenário com alertas durante a gravação, use dados sintéticos claramente identificados ou configure limiares no aplicativo.

Execute `python scripts/finalizar_readme.py` quando terminar. O script recusa gerar a galeria enquanto faltar captura.
